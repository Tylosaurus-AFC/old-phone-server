# Packages that a headless server usually does not need. Disable ONE BATCH AT A TIME and
# reboot after each: some phones refuse to boot if a package the framework needs is gone.
#   adb shell su -c "pm disable-user --user 0 <package>"      (undo: pm enable <package>)
# On Android 4.4 use `pm disable <package>`. Check the exact names on your phone with
#   adb shell pm list packages
#
# NEVER disable: com.android.permissioncontroller (system_server then crash-loops at boot),
# com.android.settings, com.android.systemui, the launcher, com.android.phone,
# com.android.providers.settings, com.android.providers.media, com.android.networkstack*,
# your keyboard (AOSP: com.android.inputmethod.latin), com.android.shell, and your root
# manager (Magisk / KingRoot). Google Play Services is safe to disable ONLY if you do not
# need Google apps on the phone any more.
#
